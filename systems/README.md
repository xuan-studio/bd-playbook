## 如何使用这几个系统

先在频道预处理台筛选公开目标，人工复核线索是否适合联系。沟通工作台使用你自己的产品知识库辅助推进，把合作承诺交给人审批。账号与执行工具需要单独配置。当前没有现成自动导入器或共享数据库，不能把“文档上的流程”理解成“接口已打通”。
