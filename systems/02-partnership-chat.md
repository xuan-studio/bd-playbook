# BD 合作沟通工作台

轩制作 · Made by XUAN · [Article](https://x.com/Yuanzhuo_labs/status/2099855596728328701)

## 解决什么问题

用专属知识库推进合作对话，关键商业承诺由人工审批。

## 代码与部署

- [独立仓库](https://github.com/xuan-studio/bd-partnership-chat-workbench)
- [部署说明](https://github.com/xuan-studio/bd-partnership-chat-workbench/blob/main/docs/DEPLOYMENT.md)

先运行不需要 API Key 的本地演示；AI 模式另需依赖和模型供应商配置。

## 输入与输出

输入：虚构或自建业务知识库、对话内容。

输出：回复建议、合作阶段、待审批事项及本地合作记录。

## 当前状态

MIT；本地演示可用，真实模型响应与外部渠道未在本次测试。

## 与其他系统的关系

各系统独立运行。本次没有实现自动数据传递、统一账号或共享知识库；后续对接将以明确的字段和人工审批边界为基础。
